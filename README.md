# Tek Çorap Anayasa Mahkemesi

Resmi adı: **Türkiye Cumhuriyeti Çamaşır Makinesi Sonrası Yargı Organı**.

Bu depo, çamaşır makinesinden tek dönen çorabın hukuki statüsünü belirlemek için kurulmuştur. Anlamlı olması şart değildir. Çalışması şarttır. İkisi de sağlandı. Tebrikler, artık bir mahkemeniz var ve yargıç çorap.

## Neden var?

Çünkü bir çorap kayboldu. Diğeri kaldı. Kalan, kaybolan adına konuşamaz. Konuşursa da mahkeme dinlemez, çünkü protokol böyledir. Protokolü biz yazdık. Protokol şudur: önce çay, sonra gerekçe, sonra yine çay.

Bu yazılım bir eğlence simülasyonudur. Gerçek bir mahkeme değildir. Kararlarını komşuya, işverene veya çamaşır makinesine ibraz etmeyiniz. Makine zaten suçunu kabul etmez.

## Kurulum

Python 3 yeter. Bağımlılık yok. Bağımlılık istemek ayıp olurdu, mahkeme mütevazıdır.

```bash
python3 mahkeme.py --renk lacivert --taraf sol --kacan sag
```

Etkileşimli duruşma:

```bash
python3 mahkeme.py
```

## Örnek hüküm

Program size bir esas numarası, bir gerekçe ve bir infaz şekli verir. İnfaz şekli genellikle “diğer çorabı da makineye ver, eşitlik sağlansın” ya da “tek çorabı bardak altlığı ilan et” biçimindedir. Temyiz yoktur. Temyiz dosyası da makineye kaçmıştır.

## Dava dosyası

- `mahkeme.py` — yürürlükteki usul.
- `ornek-dava.json` — emsal karar. Emsal, emsal olduğunu sanır.
- `.gizli/tutanak.txt` — arşiv notu. Arşiv notları okunmaz, o yüzden oradadır.

## Lisans

Çorabınız size aittir. Kaybolanın mülkiyeti tartışmalıdır. Kod ise herkese açıktır, çünkü saklamanın bir faydası görülmemiştir.
